# 관리규약 개정 도우미 래온 (來On)

공동주택 관리사무소장이 **관리규약 개정**을 법령에 맞게 쉽게 진행하도록 돕는 무료 웹앱입니다.

👉 바로 쓰기: https://kthightech-rgb.github.io/raeon-rules/

## 7단계
1. **단지·준칙** — K-apt 단지정보 자동 채우기, 경기도(제23차)·서울특별시(제19차) 관리규약 준칙 선택
2. **현행 규약 불러오기** — 한글(hwp·hwpx)·워드·PDF 파일을 조문 단위로 나누고 준칙 조문 번호와 자동으로 짝짓기
3. **개정안 작성** — 준칙 전문을 바탕으로, 준칙 공란(○○)은 현행 값으로 자동 채움 · 조문마다 준칙대로/현행 유지/직접 수정
4. **법령 검증** — 공동주택관리법령 강행규정·시행령 제19조 포함사항·공란·오탈자·인용 조문 점검(경고만 표시)
5. **일정** — 공고·동의·신고·공포 기한 자동 계산(공휴일 반영), 달력 파일 내려받기
6. **서류 만들기** — 신고서(별지 제5호서식)·개정 제안서·동의서·동의 집계표·4단/3단 비교표·요약서·개정 전문을 한글(HWPX)·워드(DOCX)·엑셀로
7. **신고 전 점검** — 관할 지자체 제출서류 대조, 법정 요건 최종 점검, 신고 후 할 일

## 알아 두실 점
- 입력값과 올린 파일은 **이 브라우저 안에서만** 처리·저장됩니다. 서버로 보내지 않습니다.
- 법령 확인(국가법령정보 OC)과 K-apt 자동 채우기(공공데이터포털 인증키)는 **소장님 본인 키**를 넣어 씁니다. 없어도 직접 입력으로 진행할 수 있습니다.
- 수록 기준: 공동주택관리법·시행령(2026.7.1. 시행)·시행규칙(2026.7.30. 시행), 경기도 준칙 제23차(2026.5.26.), 서울특별시 준칙 제19차(2026.3.31.)
- **참고용 도구**입니다. 최종 확인 책임은 입주자대표회의·관리주체에 있습니다.

## 이용 안내

- 이 앱은 래온(來On)이 만든 무료 도구이며, 국토교통부·K-apt·중앙공동주택관리지원센터·주택관리사협회의 공식 서비스가 아닙니다.
- 결과물은 작성 보조용 참고자료입니다. 법령 적용과 최종 내용의 확인·책임은 사용하는 관리주체에게 있습니다.
- 입력한 내용·파일·인증키는 이 브라우저에만 저장되며 제작자에게 전송되지 않습니다. 화면 구성용 라이브러리를 외부(jsDelivr)에서 불러오므로 접속 기록은 GitHub와 해당 CDN에 남을 수 있습니다.
